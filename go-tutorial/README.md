# Go 教程

这是一份结合 ACM 训练平台源码的 Go 入门教程。

读者已经了解基本的变量、循环、条件、函数调用和常见运算符，但还没有系统接触过 Go。

## 阅读顺序

1. [Go 语言基础](./01-language/)
2. [Go 标准库](./02-standard-library/)
3. [项目启动过程](./03-project-entry/)
4. [项目结构](./04-project-architecture/)
5. [练习](./05-practice/)

## 教程原则

- 先解释一个小概念，再回到当前项目中的代码。
- 每篇文章只解决一个主要问题。
- 不默认读者知道 Go 的特殊规则。
- 示例优先使用短代码，不直接堆积完整业务文件。
- 当前教程只做文档，不修改 `acm-platform` 源码。
