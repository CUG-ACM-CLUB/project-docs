# JavaScript 和 TypeScript 教程

面向有编程基础、没有学过 JS 和 TS 的读者 . 示例不依赖具体项目 , 不涉及前端框架 .

## 阅读路线

先学习 JS 如何执行程序 , 再学习 TS 如何检查程序中的类型 . TS 部分沿用前面的 function、object 和异步规则 , 不会另起一套执行方式 .

1. [阅读准备](./00-preparation/README.md) : 区分执行 JS 的程序与检查 TS 的工具 .
2. [JavaScript 语法](./01-javascript/README.md) : 从变量和值开始 , 逐步把数据与 function 组织成 object 和 module , 最后处理稍后才得到的结果 .
3. [JavaScript 内置对象](./02-built-ins/README.md) : 使用已有的 method 处理字符串和集合 , 再把数据转成文本或按规则匹配文本 .
4. [TypeScript 类型规则](./03-typescript/README.md) : 先限制单个值 , 再描述数据和 function 的关系 ; 学会判断未知值后 , 用泛型保留不同调用中的类型关系 .

各部分内部按索引分组阅读 . 标为查阅的篇目可以等遇到对应写法再看 . 每个代码块默认是独立例子 , 多文件例子会另行说明 .
