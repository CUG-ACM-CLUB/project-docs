# 正则表达式

`includes` 能查找固定文本 . 如果需要判断整段是否都是数字 , 或提取冒号两边的内容 , 可以用正则表达式描述匹配规则 .

## 先写一条规则

下面要求字符串非空 , 并且全部是数字 :

```js
const rule = /^\d+$/;
console.log(rule.test("123")); // true
console.log(rule.test("12a")); // false
```

`rule` 是 RegExp object . 两个 `/` 包住匹配规则 , 不属于要匹配的文本 . `test(text)` 判断文本是否匹配 , 返回 `boolean` .

规则中的 `^` 表示开头 , `\d` 表示数字 , `+` 表示前一项出现一次或多次 , `$` 表示结尾 . 四者连起来 , 就要求字符串非空且全部是数字 .

常见符号留作查阅 :

| 写法 | 含义 |
| --- | --- |
| `^`、`$` | 输入开头、结尾 ; `m` flag 会改变含义 |
| `.` | 一个字符 , 默认不匹配换行 |
| `\d` | 一个 ASCII 数字 |
| `\w` | 一个英文字母、数字或下划线 |
| `\s` | 一个空白字符 |
| `[a-z]` | 指定范围中的一个字符 |
| `*`、`+`、`?` | 前一项出现零次以上、一次以上、零次或一次 |
| `{2,4}` | 前一项出现二到四次 |
| `(abc)` | 分组并保存匹配结果 |
| 竖线选择符 | 匹配左边或右边的表达式 |

例如 `/a|b/` 匹配 `a` 或 `b` .

## 不只判断 , 还可以取出匹配内容

`test` 返回真假 . 需要取出内容时 , 使用 `exec` : 找不到返回 `null` ; 找到返回数组 , 第 `0` 项是完整匹配 , 后续项对应各个 `(...)` 分组 :

```js
const match = /^(\w+):(\d+)$/.exec("book:12");
if (match !== null) {
  console.log(match[0], match[1], match[2]); // "book:12" "book" "12"
}
console.log("a1b2".replace(/\d/g, "#")); // "a#b#"
```

`(\w+)` 和 `(\d+)` 分别取出 `book` 与 `12` . 最后一行把规则传给字符串的 `replace` , 替换所有数字 .

## 用 flag 调整匹配方式

flag 写在最后一个 `/` 后 . 上例 `/\d/g` 的 `g` 表示继续查找其他匹配 , 所以 `1` 和 `2` 都被替换 .

其他常见选项是 `i` 忽略大小写 , `m` 让 `^`、`$` 按行匹配 , `s` 让 `.` 也匹配换行 , `u` 开启 Unicode 匹配规则 .

带 `g` 的 RegExp 会保存查找位置 . 对同一个 object 反复 `test` 会继续往后查找 , 因此只判断整段文本时通常不加 `g` .

## 补充 : 从字符串创建规则

`new RegExp("\\d+")` 与 `/\d+/` 表示相同规则 . 前者的输入先经过 JS 字符串解析 , 需要用 `\\` 表示一个反斜杠 .

不要直接把普通输入当成规则拼进去 : 输入中的 `.`、`*` 等字符会有匹配含义 . 只想查找原样文本时仍使用 `includes` .
